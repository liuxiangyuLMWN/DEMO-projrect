# 车辆调度模拟器 (Vehicle Dispatch Simulator)

一个用Go语言实现的车辆调度模拟系统，用于模拟外卖/快递平台的车辆调度过程。

## 项目结构

```
Vehicle_Simulate/
├── car-simulator/
│   ├── main.go          # 主程序入口
│   ├── simulator.go     # 模拟器核心逻辑
│   ├── vehicle.go       # 车辆模型和移动逻辑
│   ├── order.go         # 订单模型和状态管理
│   ├── dispatch.go      # 调度算法实现
│   ├── map.go           # 地图和位置管理
│   └── README.md        # 项目说明（本文件）
```

## 核心功能

### 地图系统
- 20x20的二维地图
- 随机生成车辆和订单位置
- 欧几里得距离计算

### 🚗 车辆系统
- 多辆车辆同时运行
- 三种状态：空闲(`idle`)、取货中(`picking`)、送货中(`delivering`)
- 车辆每秒移动一格（优先X轴移动）
- 90%概率接受订单

### 📦 订单系统
- 动态生成订单
- 五种状态：创建(`created`)、已调度(`scheduled`)、已取货(`picked`)、已送达(`delivered`)、已取消(`cancelled`)
- 支持重试调度（最多3次）

### 调度算法
- **最近车辆算法**：选择距离最近且空闲的车辆
- 距离限制：欧几里得距离 ≤ 10
- 调度延迟：1-10秒随机延迟（用于模拟决策时间）

## 运行参数

- **时间比例**：1小时 = 360秒（总共24小时 = 8640秒）
- **地图大小**：20x20
- **车辆数量**：可配置
- **订单数量**：可配置

## 程序输出

程序会实时输出调度和配送过程：

```
[调度] 订单 O1 到车辆 V1(位置:5,8) (时间: 120秒，取货点: (12,15)，调度时间5秒)
[取货] 车辆 V1(位置:12,15) 在时间 135 完成取货，订单 O1 状态: scheduled -> picked，取货耗时: 25秒
[送货] 车辆 V1(位置:18,20) 在时间 150 完成送货，订单 O1 状态: picked -> delivered，总耗时: 45秒
```

每360秒（1小时）输出统计信息：
```
=== 第 1 小时统计 (时间: 360秒) ===
订单状态: 活跃=50, 已调度=45, 已取货=40, 已完成=35, 已取消=2
车辆状态: 空闲=3, 取货中=5, 送货中=7
完成率: 70.0%
```

## 编译运行

```bash
cd Vehicle_Simulate/car-simulator

```

## 设计理念

该模拟器旨在：
1. 模拟真实的外卖配送场景
2. 验证调度算法的有效性
3. 分析系统性能指标（如完成率、车辆利用率）
4. 为算法优化提供测试平台

## 注意事项

⚠️ **已知问题**：
- 调度延迟时间仅用于显示，未实际应用于调度过程
- 取货耗时计算包含调度延迟，可能导致时间统计不准确
- 地图边界固定为20x20，超出边界会停止移动
